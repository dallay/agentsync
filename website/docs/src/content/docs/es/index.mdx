## Elige por dónde empezar

Elige la ruta que mejor se ajuste a tu objetivo:

- **Instalar y sincronizar tu primer asistente:** sigue la guía de <BaseLink href="/guides/getting-started/">primeros pasos</BaseLink>.
- **Configurar escenarios habituales:** consulta las <BaseLink href="/guides/recipes/">recetas de configuración</BaseLink>.
- **Organizar archivos de instrucciones:** lee <BaseLink href="/concepts/instruction-files/">archivos de instrucciones</BaseLink> y <BaseLink href="/concepts/sync-types/">tipos de sincronización</BaseLink>.
- **Configurar servidores MCP o skills:** usa las guías de <BaseLink href="/guides/mcp/">integración MCP</BaseLink> y <BaseLink href="/guides/skills/">skills</BaseLink>.
- **Revisar la configuración prevista o detectar diferencias:** usa <BaseLink href="/guides/inspect/">inspeccionar configuración</BaseLink> y <BaseLink href="/reference/status-output/">referencia de salida de status</BaseLink>.
- **Revisar la compatibilidad de salida para scripts y TUI:** consulta el <BaseLink href="/contributing/cli-tui-contract/">contrato de compatibilidad de CLI y TUI</BaseLink>.
- **Automatizar la configuración del equipo o diagnosticar un problema:** consulta <BaseLink href="/guides/git-hook-automation/">automatización con Git hooks</BaseLink>, <BaseLink href="/guides/gitignore-team-workflows/">flujos de equipo con Gitignore</BaseLink> y <BaseLink href="/guides/troubleshooting/">solución de problemas</BaseLink>.

Para consultar campos y opciones, usa la <BaseLink href="/reference/configuration/">referencia de configuración</BaseLink> y la <BaseLink href="/reference/cli/">referencia de CLI</BaseLink>.
