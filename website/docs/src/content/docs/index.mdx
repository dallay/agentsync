## Pick a path

Start with the path that matches your goal:

- **Install and sync your first assistant:** follow <BaseLink href="/guides/getting-started/">Getting Started</BaseLink>.
- **Configure common setups:** follow the <BaseLink href="/guides/recipes/">Configuration Recipes</BaseLink>.
- **Organize instruction files:** read <BaseLink href="/concepts/instruction-files/">Instruction Files</BaseLink> and <BaseLink href="/concepts/sync-types/">Sync Types</BaseLink>.
- **Configure MCP servers or skills:** use the <BaseLink href="/guides/mcp/">MCP Integration</BaseLink> and <BaseLink href="/guides/skills/">Skills</BaseLink> guides.
- **Check intended configuration or drift:** use <BaseLink href="/guides/inspect/">Inspect Configuration</BaseLink> and <BaseLink href="/reference/status-output/">Status Output</BaseLink>.
- **Automate team setup or diagnose an issue:** see <BaseLink href="/guides/git-hook-automation/">Git Hook Automation</BaseLink>, <BaseLink href="/guides/gitignore-team-workflows/">Gitignore Team Workflows</BaseLink>, and <BaseLink href="/guides/troubleshooting/">Troubleshooting</BaseLink>.

For field definitions and command flags, use the <BaseLink href="/reference/configuration/">Configuration Reference</BaseLink> and <BaseLink href="/reference/cli/">CLI Reference</BaseLink>.
