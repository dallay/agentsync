## Criterios de aceptación

- Si apply reemplaza un MCP previo, revert restaura el archivo original byte a byte si sigue en el estado aplicado.
- Si el usuario modifica el archivo después de apply, revert lo conserva, avisa y retiene el journal.
- Journal fuera del repo en `dirs::data_local_dir()`, privado y con bloqueo entre procesos.
- No borrar MCP por nombre cuando no existe evidencia de propiedad registrada.
- Sin journal heredado, conservar el MCP actual con aviso; no inventar un preimage.
- Plugins, agentes deshabilitados desde `apply`, filtros de agentes y rutas compartidas quedan representados en el journal.
- La documentación cubre ubicación, permisos, ciclo de vida, migración heredada y cambios posteriores a `apply`.
